Section 3: The A-B-C-D Checklist (Cameron runs before every publish)

Cameron runs four checks every single time before it publishes. If any check fails, it does not publish and flags Shannon instead.

A
All images placed

Every image placeholder has a real URL. Hero image is set as the GHL cover photo only, never duplicated in the post body.

B
No label reading

Every image is inspected. If any image shows readable text on product packaging or labels, it is flagged and not placed.

C
Slug matches calendar

The URL slug in the post frontmatter matches the slug listed in the 30-day calendar exactly. Mismatches cause 404s.

D
URL returns 200 three times

After publishing, Cameron hits the live URL three times. All three must return HTTP 200. If any fail, it re-publishes using the DRAFT-to-PUBLISHED cycle.

Section 4: What Breaks the Pipeline and What Cameron Does

These are the four known failure modes and exactly how Cameron handles each one without Shannon having to step in (unless flagged).

Problem 1
Photo Claude does not run and no photos are committed by 8:30 AM.
Cameron's response
Waits until 8:45 AM, then sends Shannon a Telegram flag: "Photo Claude did not run today. Post for [title] is on hold. Please run Photo Claude and I will publish when photos land." This is the fix from the July 24-25 outage. Previously Cameron stayed silent and the post just did not publish.
Problem 2
fal.ai balance runs out mid-generation and Higgsfield cannot produce images.
Cameron's response
Flags the balance immediately via Telegram. Falls back to RunwayML if available, or places Pexels stock images. Flags Shannon that stock was used and photo quality should be reviewed when balance is restored.
Problem 3
GHL publish API call fails (network error, timeout, or GHL outage).
Cameron's response
Retries using the two-step method: POST to create the post as DRAFT, then PUT to set status to PUBLISHED. This avoids single-call race conditions that cause silent GHL failures.
Problem 4
URL returns 404 after the publish call appears to succeed.
Cameron's response
Re-runs the full DRAFT-to-PUBLISHED cycle. Waits 60 seconds between attempts. Verifies with three HTTP requests. If still failing after two cycles, flags Shannon.
