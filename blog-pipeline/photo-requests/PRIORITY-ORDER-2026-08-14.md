# Photo request order, 6 images a day

Read this first, then work the request files in the order below. **Do not start a set until the
one above it is delivered**, because each set is a continuity set: same woman, same clothes, same
hands, one room, cold-to-warm ramp. Splitting a set across two days breaks the continuity and the
post ships looking like five different houses.

Six a day means roughly **one full set per day with one image spare**. Day 1 uses that spare on a
single orphan image that unblocks an already-written post, which is the cheapest win available.

| 1 | `2026-08-14-fabuloso-5th.md` | 1 | ORPHAN IMAGE, uses the spare slot. The Fabuloso rewrite is fully written and its rescued set is one image short of the 4-body minimum, so ONE image ships a finished post. |

## Why this order and not another

- **Unblocking beats starting.** One image finishes Fabuloso. Five images start a post that still
  has to be written. The single image goes first.
- **Perishable before evergreen.** The GRAS story has a comment period attached to it. Red Dye 40
  runs on January 2027 deadlines. The builder post has no clock at all.
- **The steam cleaner leads because of the frame, not the date.** Six of nineteen ideas were
  killed last night for indicting Switch to America as hard as the villain. This one cannot: the
  seller refused to do a recall, so "one company you can hold to it" gets stronger.

## Standing image rules for every set below

- Beat 1 is the HERO and becomes the GHL cover ONLY. Never place it in the body.
- REAL-LIFE standard: ordinary varied everyday clothing, honest lived-in clutter, natural
  true-to-life colour. Not candy-bright, not sad-beige. Distinct real-looking people, five fingers
  per hand, visible pores.
- SHOW the real recognisable branded product with correct container shape and FRONT branding.
- **NEVER a label-reading or ingredient-panel shot.** Never anyone inspecting fine print. The
  villain is the product and the company, never the label.
- Continuity: same person, same clothes, same hands across all five beats. One room per set.
- Temperature ramp: coldest at the villain beat, warmest at the last beat.
- **NO baby, crib, nursery, high chair or toddler in any frame.** The reader is a woman 40 to 60.
- No skulls, hazmat, warning signs, cartoon fumes, green glow, or gibberish text.
- Nano Banana Pro at 4K.
